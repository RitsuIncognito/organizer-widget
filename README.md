# Органайзер — виджет для рабочего стола

Один HTML-файл без сервера и без интернета: календарь, заметки, идеи, задачи с таймером и аналитика по времени. Все данные хранятся локально в браузере (IndexedDB) и никуда не отправляются.

## Возможности

- **Календарь** на месяц. Точка под датой показывает, что на день есть записи; синяя точка значит, что там есть открытые задачи.
- **Заметки и задачи.** Переключатель «Заметка / Задача» при создании. Любую запись можно превратить в задачу и обратно.
- **Идеи** — отдельный раздел для записей без даты.
- **Скриншоты.** Ctrl+V прямо в окне или перетаскивание картинки мышкой. Клик по миниатюре открывает её на весь экран.
- **Таймер у задач.** Старт/стоп в карточке, одновременно идёт только один таймер. Текущий таймер виден в полосе сверху и в заголовке окна. Время можно добавить или убрать вручную кнопкой «+».
- **Проекты.** Метка проекта у любой записи, у каждого проекта свой цвет.
- **Аналитика** за 7, 30 или 90 дней: время сегодня и за период, среднее в день, выполненные задачи, график по дням, распределение по проектам и задачи, на которые ушло больше всего времени.
- **Поиск** по тексту и проектам, светлая и тёмная тема.
- **Резервная копия** в JSON и восстановление из неё (меню «⋯»).

## Запуск

### Windows
0. Скачайте репозиторий: кнопка **Code → Download ZIP**, распакуйте архив.
1. Положите `organizer.html` и `Organizer.bat` в одну папку.
2. Запустите `Organizer.bat` — органайзер откроется в Edge (или Chrome) отдельным компактным окном без адресной строки.
3. Чтобы окно открывалось при входе в систему, положите ярлык на `Organizer.bat` в папку автозагрузки (Win+R → `shell:startup`).

### macOS
```bash
open -na "Google Chrome" --args --app="file://$HOME/Organizer/organizer.html" --window-size=440,820
```

### Любой браузер
Просто откройте `organizer.html`.

## Хранение данных

Данные живут в хранилище браузера, привязанном к пути файла. Поэтому:
- не перемещайте `organizer.html` после начала работы (или сделайте копию и загрузите её на новом месте);
- не очищайте данные сайтов в браузере;
- время от времени сохраняйте резервную копию через меню «⋯».

Таймер продолжает считать, даже если окно закрыто: при следующем открытии время подтянется.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Enter | Сохранить запись |
| Ctrl+V | Вставить скриншот |
| Esc | Закрыть просмотр картинки |
